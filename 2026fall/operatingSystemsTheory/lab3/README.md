# Лабораторийн ажил 3 - PCB ба процессын симуляци

Энэ лабораторид `struct PCB` ашиглан 3 процессын энгийн simulation хийсэн.

## Файлууд

- `Process1.c` - random массив үүсгээд өсөхөөр эрэмбэлнэ.
- `Process2.c` - хоёр 3x3 матриц үүсгээд нэмнэ.
- `Process3.c` - тэмдэгт мөрийн тэмдэг бүрийн давтамжийг тоолно.
- `Lab3.c` - 3 процессыг round-robin маягаар ээлжлэн ажиллуулна.
- `Makefile` - файлуудыг компайл хийхэд ашиглана.

## Компайл хийх

```bash
make
```

## Ажиллуулах

Нэгдсэн програм:

```bash
./lab3
```

Тус тусад нь ажиллуулах бол:

```bash
./process1
./process2
./process3
```

Програмууд мөнхийн давталтаар ажиллана. Зогсоохдоо `CTRL + C` дарна.

## Цэвэрлэх

```bash
make clean
```

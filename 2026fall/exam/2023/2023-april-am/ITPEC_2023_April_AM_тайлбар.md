# ITPEC FE 2023 оны 4-р сарын AM - 80 асуултын тайлбар

Энэ шалгалт 80 асуулттай, 150 минутын хуучин FE Morning хэлбэртэй. Нэг асуултад дунджаар 1 минут 52 секунд ногдоно. Доорх тайлбарыг эх PDF-тэй зэрэгцүүлэн уншвал илүү ойлгомжтой.

## 1-10. Суурь онол, өгөгдлийн бүтэц, програм

### Q1 - Хариу: d

Илэрхийллийг хэсэг хэсгээр будна. `A ∩ C̄` нь A-д байгаа боловч C-д байхгүй хэсэг, `A ∩ B̄ ∩ C` нь зөвхөн A ба C-ийн давхцал, `Ā ∩ B ∩ C` нь зөвхөн B ба C-ийн давхцал. Гурван олонлогийн голын хэсэг орохгүй учраас d зураг таарна.

### Q2 - Хариу: a (`2AF3`)

Логик баруун шилжилтээр зүүн талд 0 орно. `ABCD₁₆ = 1010 1011 1100 1101₂`. Хоёр бит баруун шилжүүлэхэд `0010 1010 1111 0011₂ = 2AF3₁₆`.

### Q3 - Хариу: b (`5/16`)

4 зоосны нийт үр дүн `2⁴ = 16`. Дор хаяж 3 сүлд гэдэг нь яг 3 сүлд эсвэл 4 сүлд: `C(4,3) + C(4,4) = 4 + 1 = 5`. Иймээс `5/16`.

### Q4 - Хариу: c (`1/10`)

`C = 0` болохын тулд `A = B` байх ёстой. A, B тус бүр 0-9 гэсэн 10 утгатай тул нийт 100 хосоос `(0,0)...(9,9)` гэсэн 10 хос таарна. `10/100 = 1/10`.

### Q5 - Хариу: d (`F5_1`)

Хувьсагчийн нэр заавал A-F үсгээр эхэлнэ. Дараа нь үсэг, цифр эсвэл `_` байж болно. `F5_1` энэ дүрмийг бүрэн хангана.

### Q6 - Хариу: a (CRC)

CRC нь өгөгдлийн битүүдийг generator polynomial-оор хувааж, үлдэгдлийг хамт илгээдэг. Хүлээн авагч ижил polynomial ашиглан дахин хувааж алдаа байгаа эсэхийг шалгана.

### Q7 - Хариу: c

Pre-order traversal-ын дараалал нь `үндэс -> зүүн дэд мод -> баруун дэд мод`. Тиймээс `9, 3, 1, 6, 4, 7, 10, 14, 13`.

### Q8 - Хариу: c (`5`)

Queue нь FIFO. Үйлдлүүдийн дараа дараалал: `[1,2,3] -> [2,3,4,5] -> [3,4,5,6] -> [4,5,6] -> [5,6]`. Дараагийн `DEQ` нь 5-ыг гаргана.

### Q9 - Хариу: b (`2`)

Цифрүүдийн нийлбэр `5+4+3+2+1 = 15`. `15 mod 13 = 2`, тиймээс array-ийн 2-р байрлалд хадгална.

### Q10 - Хариу: c (Java servlet)

Servlet нь web server дээр ажиллаж динамик хариу үүсгэдэг. JavaScript болон VBScript ихэвчлэн browser талд, Java applet мөн client талд ажилладаг хуучин технологи.

## 11-24. Компьютерийн бүтэц, үйлдлийн систем, логик, мультимедиа

### Q11 - Хариу: c (Stack pointer)

`PUSH` болон `POP` нь stack дээр ажиллана. Stack-ийн оройн хаягийг заадаг тусгай регистрийг stack pointer гэдэг.

### Q12 - Хариу: b

0-д хуваах алдаа нь CPU тухайн instruction-ыг гүйцэтгэх үед дотроос үүсдэг exception буюу internal interrupt. Цахилгаан, I/O дуусах зэрэг нь гаднын шалтгаант interrupt.

### Q13 - Хариу: b (Write back)

Write back үед эхлээд зөвхөн cache шинэчлэгдэж, дараа нь block солигдох зэрэг үед main memory-д бичнэ. Иймээс memory рүү бичих тоо багасна. Write through бол өөрчлөлт бүрийг шууд memory-д бичдэг.

### Q14 - Хариу: c

3D printer нь fused filament fabrication зэрэг аргаар материалыг давхарлан бодит 3 хэмжээст биет хийдэг. a нь 3D scanner, d нь projection mapping.

### Q15 - Хариу: a (RAID 0)

RAID 0 нь өгөгдлийг хэд хэдэн дискэнд striping хийж хурдыг нэмэгдүүлдэг. Redundancy байхгүй тул нэг диск эвдэрвэл бүх өгөгдөл алдагдах эрсдэлтэй.

### Q16 - Хариу: c

Найдвартай байдлын дараалал: `dual system > cold standby > simplex`. Dual system зэрэг ажиллах нөөцтэй, cold standby асааж шилжүүлэх хугацаа шаарддаг, simplex нөөцгүй.

### Q17 - Хариу: a (`98%`)

Нэг секундэд interrupt-д зарцуулах хугацаа: `400 × 50 μs = 20,000 μs = 0.02 s`. CPU 2%-ийг printer-д зарцуулж, бусад ажилд `100%-2%=98%` үлдээнэ.

### Q18 - Хариу: b (`4.75 ms`)

SRTF дараалал: P1 `0-2`, P2 `2-5`, P4 `5-9`, P1 `9-15`, P3 `15-22`. Waiting time нь P1=7, P2=0, P3=12, P4=0. Дундаж: `(7+0+12+0)/4 = 4.75 ms`.

### Q19 - Хариу: d

Incremental backup нь өмнөх backup-аас хойш өөрчлөгдсөн файлуудыг л авна. Авсны дараа update flag-ийг reset хийнэ. Flag-ийг хэвээр үлдээвэл differential backup-ын шинж болно.

### Q20 - Хариу: c

Өгсөн илэрхийлэл: `ĀBC + AC = C(ĀB + A)`. Boolean дүрмээр `A + ĀB = A + B`, тэгэхээр `C(A+B)` болно. Энэ нь эхлээд A, B-г OR хийгээд үр дүнг C-тэй AND хийсэн c хэлхээ.

### Q21 - Хариу: c (XOR)

Дөрвөн NAND gate-аар байгуулсан энэ түгээмэл хэлхээний гаралт `A XOR B`. A, B хоёр өөр үед 1, ижил үед 0 гарна.

### Q22 - Хариу: b (`8D`)

Clock-ийн rising edge бүр дээр Data-ийн тухайн утгыг уншиж, өмнөх битүүдийг дээш шилжүүлнэ. Strobe өсөх хүртэлх сүүлийн 8 битийг дарааллаар бичихэд `1000 1101₂`, hexadecimal-аар `8D`.

### Q23 - Хариу: d

Outline font нь дүрсийг шугам, муруйн томьёогоор хадгалдаг тул хэмжээг өсгөхөд ирмэг нь шаталж муудахгүй. Bitmap font тодорхой pixel хэмжээтэй.

### Q24 - Хариу: d (`ойролцоогоор 350 Mbps`)

`800 × 600 × 24 bit × 30 frame/s = 345,600,000 bit/s`. Энэ нь ойролцоогоор 350 Mbps.

## 25-35. Өгөгдлийн сан ба сүлжээ

### Q25 - Хариу: b

Relational database нь өгөгдлийг мөр, баганатай хоёр хэмжээст table хэлбэрээр дүрсэлдэг. Pointer нь hierarchical/network DB, tag нь XML, data ба procedure-г хамт хадгалах нь object-oriented загвар.

### Q26 - Хариу: d (`OS`)

`O -> T`, `S -> M -> N`, мөн `OS -> P`. Тэгэхээр OS-оос O, S, T, M, N, P бүгд гарна. Иймээс OS нь бүх attribute-ийг тодорхойлох key.

### Q27 - Хариу: c

Primary key нь unique бөгөөд NULL байж болохгүй. Foreign key нь холбоотой table-ийн primary key утгатай таарах ёстой боловч олон мөрөнд давтагдаж болно.

### Q28 - Хариу: b

UML multiplicity-гаар нэг Employee нь `1..*` Department-д харьяалагдаж болно. Тиймээс ажилтан нэгэн зэрэг олон хэлтэст харьяалагдаж болох b зөв.

### Q29 - Хариу: a

a нь `emp_id=4`, `emp_name='Hulk'` гэж зөв type, зөв уртаар оруулж salary-г NULL үлдээсэн. b-д salary ба name-ийн утгын байрлал солигдсон, c-д нэр 10 тэмдэгтээс урт, d-д salary 4 орноос их.

### Q30 - Хариу: b

Index нь хайлтын түлхүүрээс тухайн record-ийн storage location руу хурдан хүрэх бүтэц. Search хурд нэмэгддэг ч нэмэлт зай эзэлж, INSERT/UPDATE бага зэрэг удааширч болно.

### Q31 - Хариу: c (DNS)

DNS нь domain/host name-ийг IP address-тэй mapping хийдэг. Жишээ нь `example.com -> 93.x.x.x`.

### Q32 - Хариу: a

`255.255.255.255` нь limited broadcast address. Router цааш дамжуулахгүй бөгөөд тухайн local subnet-ийн бүх төхөөрөмж хүлээн авна.

### Q33 - Хариу: b (`62`)

`/26` тул host bit `32-26=6`. Нийт `2⁶=64` address, network ба broadcast гэсэн 2-г хасвал `62` host address.

### Q34 - Хариу: c (NTP)

NTP буюу Network Time Protocol нь client, server-ийн цагийг синхрончилно. ARP нь IP-MAC, ICMP нь control/error, RIP нь routing-д ашиглагдана.

### Q35 - Хариу: c (MIME)

MIME нь email header болон content type-ийг өргөтгөж text-ээс гадна зураг, audio, attachment дамжуулах боломж өгдөг. SMTP бол mail илгээх протокол.

## 36-45. Мэдээллийн аюулгүй байдал

### Q36 - Хариу: a (Bot)

Bot нь халдварласан төхөөрөмж дээр attacker-ийн тушаалаар ажиллаж, DDoS зэрэг бусад компьютер рүү довтолгоо хийдэг. Олон bot нийлбэл botnet болно.

### Q37 - Хариу: d

Хуурамч сайт руу хуурч оруулан хувийн мэдээлэл авах нь confidentiality буюу нууцлалыг зөрчинө. a нь availability, мэдээлэл эвдэх нь integrity-д илүү хамаарна.

### Q38 - Хариу: b

Нууц message илгээхдээ receiver-ийн public key-ээр encrypt хийж, зөвхөн receiver өөрийн private key-ээр decrypt хийнэ. Нийтийн түлхүүрийг нууцаар хуваалцах шаардлагагүй.

### Q39 - Хариу: b

Targeted email буюу spear phishing нь хүлээн авагчийн ажил, байгууллагатай холбоотой мэт subject/body ашиглан итгүүлдэг. Олон хүнд ялгалгүй илгээсэн mail нь targeted биш.

### Q40 - Хариу: c

Back door нь хэвийн authentication, албан ёсны ажиллагааг тойрч системд орох нууц зам. Port scanner болон buffer overflow attack өөр ойлголт.

### Q41 - Хариу: a (`$20,000`)

Single Loss Expectancy: `200,000 × 20% = 40,000`. Annual Loss Expectancy: `40,000 × 0.5 = 20,000`.

### Q42 - Хариу: d

Residual risk гэдэг нь хамгаалалтын арга хэмжээ авсны дараа ч үлдсэн эрсдэл. Арга хэмжээ авахаас өмнөх эрсдэлийг inherent risk гэж нэрлэдэг.

### Q43 - Хариу: d (Sandbox)

Sandbox нь сэжигтэй program-ыг тусгаарлагдсан орчинд ажиллуулж зан төлөвийг ажиглана. Ингэснээр жинхэнэ system, network рүү хандах боломжийг хязгаарлана.

### Q44 - Хариу: c

PC request илгээхдээ түр source port `1024+`, destination нь web server-ийн `80`. Server-ийн response source port 80-аас PC-ийн анхны `1024+` порт руу буцна.

### Q45 - Хариу: d (SMTP-AUTH)

SMTP-AUTH нь outgoing mail server дээр mail илгээгчийг authentication хийдэг. APOP/POP3S нь mail хүлээн авах, S/MIME нь encryption ба digital signature-д хэрэглэгдэнэ.

## 46-60. Software engineering, project, service, audit

### Q46 - Хариу: d (Process)

DFD-д дугуй тэмдэг нь process, сум нь data flow, хоёр параллель шугам нь data store, дөрвөлжин нь external entity-г илэрхийлнэ.

### Q47 - Хариу: c (Portability)

Нэг архитектурт зориулсан program-ыг өөр архитектур дээр ажиллуулахад хялбар өөрчилж болох чанар нь portability.

### Q48 - Хариу: a

Суулгасан алдааны илрүүлэлтийн хувь бодит алдааныхтай адил гэж үзнэ: `m/S = (n-m)/T`. Энд `n-m` нь олдсон бодит алдааны тоо.

### Q49 - Хариу: c

Branch coverage-д decision-ийн TRUE ба FALSE хоёр үр дүнг хоёуланг ажиллуулах хэрэгтэй. `A=false, B=false` үед `A OR B=false`; `A=true, B=true` үед true. Иймээс c-ийн хоёр testcase хангалттай.

### Q50 - Хариу: d (Reverse engineering)

Бэлэн source program-аас design model, жишээ нь UML class diagram гаргахыг reverse engineering гэдэг. Model-оос code үүсгэх нь forward engineering.

### Q51 - Хариу: a (Refactoring)

Refactoring нь гаднах behavior/specification-ийг өөрчлөхгүйгээр дотоод code structure-ийг цэвэрлэж, maintainability-г сайжруулна.

### Q52 - Хариу: a

Stakeholder нь project-д шууд эсвэл шууд бусаар нөлөөлөх, эсвэл үр дүнд нь нөлөөлөгдөх хүн, бүлэг, байгууллага. Зарим нь ашиг, зарим нь сөрөг нөлөө авч болно.

### Q53 - Хариу: d (Scope)

Objective, deliverable, requirement, boundary-г тодорхойлох болон эдгээрийн өөрчлөлтийг хянах нь scope management-ийн ажил.

### Q54 - Хариу: b (`SPI=0.75`, `CPI=0.6`)

Earned Value `EV = 80,000 × 75% = 60,000`. `SPI = EV/PV = 60,000/80,000 = 0.75`. `CPI = EV/AC = 60,000/100,000 = 0.6`. Хоёулаа 1-ээс бага тул хугацаа хоцорч, зардал хэтэрсэн.

### Q55 - Хариу: d

Function Point нь input, output, file, interface зэрэг хэрэглэгчид харагдах function-уудыг тоолж, complexity-ээр тохируулан software size-ийг үнэлдэг. Programming language-аас харьцангуй хамаарал багатай.

### Q56 - Хариу: a

Хуваалцдаг asset-ийг андуурч устгавал түүнд түшиглэсэн бусад IT service доголдож incident гарна. Харин b-d нь устгах ёстой asset-ийг үлдээснээс гарах үргүй зардлууд.

### Q57 - Хариу: c

Trend analysis нь resource usage-ийн өнгөрсөн хугацааны өөрчлөлтийг ажиглаад ирээдүйн өсөлт, бууралтыг таамаглана.

### Q58 - Хариу: a

Эвдэрсэн component-ийг салгаж, чухал function-уудаа багасгасан горимоор үргэлжлүүлэхийг fallback operation гэдэг. Checkpoint-оос дахин ажиллуулах нь restart/recovery, backup хийхийг restore гэж нэрлэхгүй.

### Q59 - Хариу: d

User requirement хангагдах эрсдэлийг бууруулахын тулд system design document-ийн review-д user department бодитоор оролцсон эсэхийг шалгана.

### Q60 - Хариу: b

Data entry-ийн үр дүнгийн жагсаалтыг business department руу буцааж өгснөөр эх баримт бүр зөв боловсруулагдсан эсэхийг owner шалгана. Entry ажилтан өөрөө алдааг дур мэдэн засах ёсгүй.

## 61-80. Бизнес, менежмент, үйлдвэрлэл

Greenhouse control нь temperature, humidity зэрэг sensor утгаас хамаарч heating, ventilation зэрэг state хооронд шилжинэ. Ийм behavior-д state transition diagram тохиромжтой.

### Q63 - Хариу: a (Digital divide)

PC, Internet ашиглах боломж болон чадварын ялгаанаас үүсэх эдийн засаг, нийгмийн зөрүүг digital divide гэдэг.

### Q65 - Хариу: c

Green procurement нь байгаль орчинд үзүүлэх ачаалал багатай product, service-ийг худалдан авахдаа давуу сонгох бодлого.

### Q66 - Хариу: d (Crowdfunding)

Website дээр нийтэлсэн project-ийг дэмжсэн олон хүнээс бага багаар хөрөнгө босгож, хариуд нь product, эрх зэрэг өгөх механизмыг crowdfunding гэдэг.

### Q67 - Хариу: b

Maturity stage-д demand өсөлт саарч, зах зээл сегментлэгдэж, өрсөлдөөн ширүүснэ. Product differentiation, шинэ model, cost reduction чухал болдог.

### Q68 - Хариу: d

Tacit knowledge нь бичгээр бүрэн тайлбарлахад хэцүү, дадлагаар сурдаг мэдлэг. Дугуй унах чадвар үүний сонгодог жишээ; жагсаалт, manual бол explicit knowledge.

### Q69 - Хариу: c

Core technology нь өрсөлдөгч амархан дуурайж чадахгүй, компанид урт хугацааны давуу тал өгдөг. Дахин давтагдашгүй engine idle-reduction technology үүнд орно.

### Q70 - Хариу: c (Process C)

Шаардлагатай ба боломжит цагийг харьцуулна. A: `400 <= 3×150=450`; B: `300 <= 320`; C: `700 > 4×170=680`; D: `1200 <= 7×180=1260`. Зөвхөн C хүчин чадал дутна.

### Q71 - Хариу: c

Cryptocurrency mining нь transaction-ийг шалгах, block-ийн тооцоонд оролцсоныхоо төлөө cryptocurrency reward авах ажиллагаа.

### Q72 - Хариу: d

Sharing economy нь хувь хүмүүс ашиглахгүй байгаа байр, машин, багаж зэрэг asset-аа platform/social function ашиглан хуваалцах, түрээслэх, зээлдүүлэх механизм.

### Q73 - Хариу: c

Digital signage нь зураг, video, текст мэдээлэл харуулдаг электрон самбар. Дэлгүүр, буудал, сургуульд түгээмэл хэрэглэнэ.

IoT-ийн “things” нь Internet эсвэл хаалттай network-д холбогдох боломжтой олон төрлийн зүйлсийг хамарна. Analog sensor ч converter/controller-оор дамжин IoT-ийн хэсэг болж болно.

On-the-Job Training нь ажлын байран дээр дарга, ахлах ажилтны заавраар бодит ажил хийж мэдлэг, ур чадвар эзэмших сургалт.

### Q76 - Хариу: b (Corporate governance)

Corporate governance нь компанийг хэний төлөө, яаж удирдаж байгааг хянах тогтолцоо. Ил тод байдал, удирдлагын хариуцлага, дотоод хяналтыг сайжруулна.

### Q77 - Хариу: b

ABC analysis нь барааг борлуулалт, ашиг зэрэг үзүүлэлтээр ихээс бага руу жагсааж, cumulative ratio-аар A, B, C бүлэгт хуваадаг. A бүлэгт хамгийн чанга хяналт тавина.

### Q78 - Хариу: d (Scatter diagram)

Хоёр хувьсагчийг x, y тэнхлэгт тавьж хэмжилтийн хос утгуудыг цэгээр тэмдэглэдэг график нь scatter diagram. Энэ нь correlation харахад ашигтай.

### Q79 - Хариу: b (`$320,000`)

Нэгжийн contribution margin: `80-48=32`. Break-even quantity: `128,000/32=4,000` ширхэг. Борлуулалтын мөнгөн дүн: `4,000×80 = $320,000`.

### Q80 - Хариу: d (ISO)

WTO-ийн гишүүн орнуудын төрийн байгууллагад өргөн хэрэглэгдэх product-д international standard болох ISO хамгийн тохиромжтой. ANSI, FCC нь АНУ-ын, IEEE нь мэргэжлийн байгууллагын стандарт.

## Цээжлэхэд хэрэгтэй гол томьёонууд

- Host address: `2^(host bit) - 2`
- Video bandwidth: `өргөн × өндөр × color bit × frame/second`
- `SLE = Asset Value × Exposure Factor`
- `ALE = SLE × Annual Rate of Occurrence`
- `SPI = EV / PV`, `CPI = EV / AC`
- Break-even quantity: `Fixed Cost / (Selling Price - Variable Cost)`
- Break-even sales: `Break-even quantity × Selling Price`

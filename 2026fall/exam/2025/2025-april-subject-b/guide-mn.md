## Хариу

`1f 2d 3b 4g 5a 6h 7b 8f 9c 10e 11g 12h 13c 14f 15f 16c 17e 18e 19i 20g`

2024 оноос Subject B нь хуучны PM хэсгийг орлосон. Энэ шалгалт 20 асуулттай, 100 минут үргэлжилнэ. Доорх тайлбарт blank бүрийг яагаад сонгосныг code trace болон scenario-ийн шалтгаантай нь үзүүлэв.

## Q1. Leap year шалгах

**Хариу: f.**

Leap year-ийн дүрэм нь дараалалтай. 400-д хуваагдвал leap year, 100-д хуваагдвал leap year биш, бусад үед 4-д хуваагдвал leap year. Иймээс эхний шалгалт `year mod 400 = 0`, түүний үр дүн `true`; дараагийн тусгай шалгалт `year mod 100 = 0` байна.

## Q2. Perfect number

**Хариу: d.**

Perfect number гэдэг нь өөрөөс нь бусад эерэг хуваагчдын нийлбэр өөртэй нь тэнцүү тоо. `k` нь хуваагч мөн эсэхийг `n mod k = 0` гэж шалгаж, мөн бол `sum ← sum+k` хийнэ. Жишээ нь 6-ын хувьд `1+2+3=6`.

## Q3. Хасалтаар GCD олох

**Хариу: b.**

Их тооноос бага тоог хассаар хоёр тоог тэнцүүлнэ:

```text
(98,56) → (42,56) → (42,14) → (28,14) → (14,14)
```

Program-ийн хэвлэх дараалалтай таарах сонголт нь b.

## Q4. Binary цифрүүдийг decimal болгох

**Хариу: g.**

`num mod 10` нь баруун захын binary цифрийг авна. Түүнийг одоогийн орны жин `place`-аар үржүүлж нэмнэ. Баруунаас зүүн тийш орны жин `1,2,4,8,...` болох тул давталт бүрийн дараа `place ← place×2`.

## Q5. Математик илэрхийлэл

**Хариу: a.**

Эхлээд x, y-ийн квадрат язгуурыг тус тус олно. Дараа нь нийлбэрийг квадрат зэрэгт дэвшүүлдэг тул нийт илэрхийлэл нь `(√x+√y)²`.

## Q6. Gray code-оос binary руу

**Хариу: h.**

Gray code-ийг binary болгохдоо утгыг баруун тийш нэг bit shift хийж, өмнөх үр дүнтэй XOR хийнэ:

```text
z ← z >> 1
y ← y XOR z
```

`z` 0 болох хүртэл энэ үйлдлийг давтана.

## Q7. Recursive binary search

**Хариу: b.**

`{1,2,3,4,5,6}` дотроос 5 хайя. Эхний `mid=3`, утга нь 3 тул баруун хагасыг нэг удаа recursive дуудна. Дараагийн `mid=5`, энд утга олдоно. Тиймээс recursive call нэг удаа.

## Q8. Stack-аас pop хийх

**Хариу: f.**

Stack нь LIFO. `sp` оройн элементийг зааж байгаа тул эхлээд `retvar ← stack[sp]` гэж утгаа авна, дараа нь `sp ← sp−1` гэж оройг нэгээр буулгана.

## Q9. Хоёр binary tree ижил эсэх

**Хариу: c.**

- `p` ба `q` хоёулаа undefined бол true. Иймээс эхний холбоос `and`.
- Аль нэг нь undefined бол false. Иймээс дараагийн холбоос `or`.
- Зүүн болон баруун subtree хоёулаа ижил байж сая нийт мод ижил болно. Иймээс эцсийн холбоос `and`.

## Q10. Doubly linked list-ийн сүүлийн node устгах

**Хариу: e.**

`current.next` undefined болох хүртэл явбал `current` хамгийн сүүлчийн node дээр ирнэ. Олон элементтэй үед өмнөх node-ийг төгсгөл болгохын тулд `current.prev.next ← undefined`.

## Q11. Counting sort

**Хариу: g.**

`s[value]` нь тухайн value хэдэн удаа гарсныг хадгална. Өгсөн array-д:

```text
s = {2,1,1,3,0,1,0,0,1,2,0}
```

Гадаад loop-ийн `i` нь хэвлэх утга, дотоод loop нь түүнийг `s[i]` удаа хэвлэнэ.

## Q12. Hamming distance

**Хариу: h.**

Hamming distance нь ижил index дээрээ өөр байгаа тэмдэгтийн тоо. Тиймээс шалгах нөхцөл нь `s1[i] ≠ s2[i]`. Array-уудын урт өөр бол бодох боломжгүй тул −1 буцаана.

## Q13. Maximum subarray

**Хариу: c.**

Subarray тасралтгүй байх ёстой. Эхлэл `i` бүр дээр төгсгөлийн `j` нь мөн `i`-ээс эхэлж, n хүртэл явна. `sum>max` болох үед олдсон subarray-ийн төгсгөлийн index нь одоогийн `j`.

## Q14. Cosine-ийн Maclaurin series

**Хариу: f.**

Series-ийн дараагийн гишүүнийг өмнөх `term`-ээс гаргаж байна. Давталт нь тухайн гишүүний absolute value маш бага болох хүртэл үргэлжилнэ. Cosine-д зэрэг нь 2-оор өсдөг тул recurrence-д `y²` хэрэглэнэ.

## Q15. Minkowski distance

**Хариу: f (`10`, `6`).**

Хоёр array-ийн absolute зөрүүнүүд `1,5,3,1`.

- `n=1`: `1+5+3+1=10`
- `n=2`: `√(1²+5²+3²+1²)=√36=6`

`n` ихсэхэд хамгийн том зөрүү болох 5 руу дөхнө.

## Q16. Craps Monte Carlo simulation

**Хариу: c.**

Дахин шидэх үед `newsum` нь анхны sum-тай тэнцээгүй **ба** 7 болоогүй хооронд үргэлжилнэ. Иймээс `and` хэрэглэнэ. Ойролцоо ялалтын магадлал `wins_sum/n`, харьцангуй алдаа `|(result−pt)/pt|`.

## Q17. Social engineering ба password attack

**Хариу: e.**

Эхний халдлагад receptionist-ийг утсаар хуурсан тул ажилтнуудад social engineering-ийн сургалт өгнө. Хоёр дахь хэсэгт password list-ээр олон удаа login оролдсон тул дараалсан буруу оролдлогын дараа account lock хийх нь шууд хамгаалалт.

## Q18. Том файлд hybrid encryption хэрэглэх

**Хариу: e.**

Файлыг KDF-ээр сайжруулсан password буюу symmetric key-ээр encrypt хийх нь хурдан. Password-ийг recipient-ийн public key-ээр asymmetric encryption хийж явуулбал зөвхөн recipient private key-ээрээ тайлна.

## Q19. Internal file санамсаргүй нийтлэх

**Хариу: i.**

Алдааны тодорхой шинж нь `For Internal Use` watermark. Ийм watermark-тай файлыг public directory-д upload хийхийг automated tool-оор хориглох нь хамгийн шууд preventive control. Public directory дахь файлуудыг тогтмол шалгах нь алдааг хурдан илрүүлэх detective control.

## Q20. Credential stuffing-ээс хамгаалах

**Хариу: g.**

Нэг password-ийг олон сайтад давтан ашигласан, олон account/password pair оролдсон тул credential stuffing байна. MFA нэмбэл password алдагдсан ч дангаараа хангалтгүй. Ердийн бус улсаас login хийсэн тохиолдолд alert өгөх нь халдлагыг хурдан илрүүлнэ.

## Subject B бодох арга

1. Blank бүрийн өмнөх ба дараах хувьсагчийн утгыг жижиг жишээгээр мөрдөх.
2. Array index 0 эсвэл 1-ээс эхэлж байгааг эхлээд тэмдэглэх.
3. Loop дуусах нөхцөлд `and` ба `or`-ыг truth table-аар шалгах.
4. Security scenario-д эхлээд attack-ийн шалтгааныг, дараа нь түүнд шууд нөлөөлөх control-ийг сонгох.

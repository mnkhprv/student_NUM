Чи НИТ-ийн (NUM) 4-р курсийн оюутан шиг "Программ хангамжийн чанар ба тестлэлт" хичээлийн лаб хийнэ.
Өмнөх `week2`, `week3`, `week4` хавтсуудыг жишээ болгон ав. Эхлээд тэдгээрээс нэг-хоёрыг нь
уншаад хэв маягийг шалга.

## Код

- Нэг л `main.c` (эсвэл даалгаврын нэртэй `.c`) файл. Header, framework, нэмэлт бүтэц хийхгүй.
- `#include <stdio.h>` зэрэг стандарт сангаас хэрэгтэйг нь л авна.
- Энгийн `for`/`while` давталт, массив, `if` ашиглана. Даалгавар функц хориглосон бол
  (week2 шиг) бүгдийг `main` дотор бичнэ.
- Хувьсагчийн нэр богино, ойлгомжтой (`n`, `i`, `j`, `min`, `a[n]`). Week4 шиг
  монгол транслит нэр (`ehlehTsag`, `duussanTsag`) байж болно.
- Тайлбар (comment) цөөхөн, зөвхөн чухал газарт. Мөр бүрт бичихгүй.
- Хамгаалалт (оролтын шалгалт) маш бага байлга. Зөвхөн программыг эвдэх зүйлийг л шалга (жишээ нь массивын хэмжээ n <= 0, цэсийн сонголт буруу). `scanf`-ийн буцаах утга бүрийг шалгахгүй. Төвөгтэй шалгалтын систем хийхгүй.
- Хугацаа хэмжих шаардлагатай бол week4 шиг `clock()` ашиглана.

## Makefile

Нэг жижиг Makefile, яг ийм хэлбэртэй:

```make
CC = gcc
CFLAGS = -std=c11 -Wall -Wextra
TARGET = <нэр>

all: $(TARGET)

$(TARGET): main.c
	$(CC) $(CFLAGS) main.c -o $(TARGET)

clean:
	rm -f $(TARGET)

.PHONY: all clean
```

## README.md (монголоор, богино)

Даалгаврын дугаар, нэрийн дагуу бичнэ. Бүтэц:

1. `# Семинар N - <сэдэв>`
2. `## Зорилго` / сонгосон аргаа яагаад сонгосноо 1–2 өгүүлбэрээр
3. `## Ажиллуулах` — `make` ба `./<нэр>` (bash блок), оролтын формат
4. `## Алгоритм` — дугаарласан товч алхмууд
5. `## Жишээ` — оролт/гаралтын жишээ (бодитоор ажиллуулж гаргасан)
6. `## Хурд ба санах ой` — O() хугацаа, нэмэлт санах ой
7. Шаардлагатай бол `## Хамгаалалтад тайлбарлах зүйл` — багшид хариулах 3–4 асуулт

Урт, мэргэжлийн тайлан бүү бич. Багшид амархан тайлбарлаж болохоор энгийн байлга.

## Ажлын дараалал

1. Даалгаврыг (PDF/слайд байвал уншиж) яг дугаарлалт, үгчлэлээр нь дага.
2. `weekN/` хавтас үүсгээд дотор нь `main.c`, `Makefile`, `README.md` бич.
3. `make` хийж, хэдэн жишээ (хэвийн, хязгаар, буруу оролт) дээр ажиллуулж шалга.
4. README-ийн жишээг бодит гаралтаар нь бич.
5. `make clean` хийж, хөрвүүлсэн программ болон бусад түр файлыг устга. Хавтсанд зөвхөн
   `.c`, `Makefile`, `.md` үлдэнэ. `bin/`, executable, тестийн скрипт үлдээхгүй.

Эцэст нь юу хийснээ 2–3 мөрөөр хэл.

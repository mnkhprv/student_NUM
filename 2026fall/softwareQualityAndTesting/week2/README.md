# Семинар 2 - Тоог хөрвүүлэх программ

## Зорилго

Аравтын болон хоёртын тооллын системийн бодит тоог хооронд нь
хөрвүүлэх энгийн C программ бичив. Даалгаврын шаардлагын дагуу хэрэглэгчийн
функц ашиглаагүй бөгөөд бүх үйлдэл `main` функцэд хийгдэнэ.

## Ажиллуулах

```bash
make
./number_converter
```

Ажиллуулсны дараа хөрвүүлэх чиглэлийг сонгоно:

```text
1. Аравтын тоог хоёртын системд хөрвүүлэх
2. Хоёртын тоог аравтын системд хөрвүүлэх
```

## Ашигласан алгоритм

### Аравтын тоог хоёртын системд хөрвүүлэх

1. Тоог тэмдэгт мөрөөр уншаад `.` тэмдэг хүртэлх цифрүүдээр бүхэл
   хэсгийг, түүнээс хойших цифрүүдээр бутархай хэсгийг байгуулна.
2. Бүхэл хэсгийг 2-т хувааж, үлдэгдлүүдийг хадгална.
3. Үлдэгдлүүдийг урвуу дарааллаар хэвлэнэ.
4. Бутархай хэсгийг 2-оор үржүүлж, гарсан бүхэл хэсгийг дарааллаар
   хэвлэнэ.
5. Бутархай хэсгийг хамгийн ихдээ 16 хоёртын орон хүртэл гаргана.

Жишээ нь `15.75` мөрийн `.`-ийн өмнөх `15` нь бүхэл хэсэг, дараах
`75` нь бутархай хэсэг болно. `strtok`, `atoi`, `strlen` зэрэг нэмэлт
функц ашиглахгүй, нэг энгийн давталтаар салгаж тооцоолно.

### Хоёртын тоог аравтын системд хөрвүүлэх

1. Бүхэл хэсгийн цифр бүр дээр `үр дүн = үр дүн * 2 + цифр` үйлдлийг
   хийнэ.
2. Бутархай хэсгийн цифрүүдийг `1/2`, `1/4`, `1/8`, ... утгаар үржүүлж
   үр дүнд нэмнэ.
3. Оролтод 0, 1-ээс өөр цифр байвал алдаа мэдээлнэ.

## Жишээ

```text
15.75(10) = 1111.11(2)
10.101(2) = 2.625(10)
```

## Хамгаалалтад тайлбарлах зүйл

- Бүхэл тоог яагаад 2-т давтан хуваадаг вэ?
- Үлдэгдлийг яагаад урвуу дарааллаар уншдаг вэ?
- Бутархай хэсгийг яагаад 2-оор үржүүлдэг вэ?
- Хоёртын бутархайн орны утга яагаад `1/2`, `1/4`, `1/8`, ... байдаг вэ?

Программд зөвхөн энгийн давталт, нөхцөл, массив болон стандарт
`scanf`, `printf` үйлдлүүдийг ашигласан.

## Хурд ба санах ой

- Оролтын цифр бүрийг нэг удаа боловсруулдаг тул ажиллах хугацаа `O(n)`.
- Динамик санах ой ашиглахгүй.
- `64` ширхэг `char` массив, `80` тэмдэгтийн оролтын массив ашиглана.
- Рекурс болон хэрэглэгчийн функц ашиглахгүй.

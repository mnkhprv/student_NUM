# Семинар 4 - Эрэмбэлэлт

Слайд дээр 2 арга байсан: сонголттой эрэмбэлэлт, оруулгын эрэмбэлэлт.
Би **оруулгын эрэмбэлэлт (Insert sorting)**-ийг сонгосон. Учир нь нэг л массив ашиглаж
(нэмэлт санах ойгүй), аль хэдийн эрэмбэлэгдсэн үед O(n) хугацаанд ажилладаг.

## Ажиллуулах

```bash
make
./sort
```

Эхлээд n, дараа нь n ширхэг бодит тоо оруулна. Массивыг яг `n` элементтэй зарласан тул илүү санах ой авахгүй.

## Алгоритм

1. Эхний элемент нь эрэмбэлэгдсэн хэсэг гэж үзнэ.
2. Дараагийн элементийг (`k`) авч, түүнээс том элементүүдийг нэг байраар баруун тийш шилжүүлээд `k`-г зохих байранд тавина.
3. Үүнийг сүүлийн элемент хүртэл давтана.
4. Анхны болон эрэмбэлсэн хүснэгтийг хэвлэнэ.

## Жишээ

```text
Оролт: 5 / 5.5 2 9 1.25 -3
Гаралт: 5.5 2 9 1.25 -3
        -3 1.25 2 5.5 9
```

## Хурд ба санах ой

- Хугацаа: хамгийн муу үед O(n²), эрэмбэлэгдсэн үед O(n).
- Санах ой: O(1) нэмэлт (`k`, `i`, `j`), зөвхөн `n` элементтэй нэг массив.
- Хэрэглэгчийн функц болон төрөл хувиргалт ашиглаагүй.

# Хоёртын хайлт (Binary search)

Эхлээд массивыг сонголттой эрэмбэлэлтээр эрэмбэлээд, дараа нь хоёртын хайлт хийнэ.

## Ажиллуулах

```bash
make
./search
```

Оролт: `n`, `n` ширхэг тоо, хайх утга `x`.
Гаралт: анхны массив, эрэмбэлсэн массив, `x`-ийн **эрэмбэлсэн массив доторх индекс** (0-ээс эхэлнэ), хайлтын хугацаа. Олдохгүй бол `baikhgui` гэж хэвлэнэ.

## Алгоритм

1. `i = 0`, `j = n - 1`.
2. `i <= j` бол 3-т, үгүй бол олдсонгүй (`baikhgui`).
3. Голын индекс `m = i + (j - i) / 2` (`i + j` халихаас сэргийлнэ).
4. `a[m] == x` бол `break` хийж гарна, үгүй бол 5-д.
5. `a[m] < x` бол `i = m + 1`, үгүй бол `j = m - 1`. Дараа нь 2-т очно.

Давталтаас гарсны дараа: `i > j` бол олдсонгүй, үгүй бол `m` нь хайсан индекс.
Тусдаа `ans` эсвэл `found` хувьсагч хэрэггүй.

## Жишээ

```text
Оролт: 5 / 9 2 7 1 5 / 7
Анхны:        9 2 7 1 5
Эрэмбэлсэн:  1 2 5 7 9
Гаралт: Index: 3
```

## Хурд ба санах ой

- Хугацаа: хайлт O(log n) (эрэмбэлэлт O(n²)).
- Санах ой: хайлт O(1) нэмэлт (зөвхөн `i`, `j`, `m`), нэг массив `a[n]`, рекурс ашиглаагүй.

# Software Project Management - Learning Guide

Энэ хавтас дотор ажиллахдаа эхлээд хичээлийн материал болон өмнө хийсэн
семинарын ажлыг судалж, дараагийн даалгаврыг түүнтэй уялдуулж хийнэ.

## Хавтасны бүтэц

- `lectures/` - Багшийн лекцийн PDF материалууд.
- `seminar_ref_docx/` - Семинар, лабораторийн заавар болон жишиг DOCX файлууд.
- `done_seminars/` - Манай багийн бодитоор хийж дуусгасан ажлууд.

`seminar_ref_docx/` дахь файлыг шууд хуулж манай ажил гэж үзэж болохгүй. Тэдгээрийг
даалгаврын шаардлага, бүтэц, аргачлалыг ойлгох эх сурвалж болгон ашиглана.

## Одоогийн төслийн нөхцөл

- Төслийн сэдэв: **Smart Home Environment & Automation Monitoring**.
- Багийн нэр: **Бамбарууш**.
- `done_seminars/Copy of wbs.docx` файлд манай багийн хийсэн WBS болон
  Tailoring + Project Evaluation ажил хамт байгаа.
- Шинэ ажил хийхдээ энэ файл дахь төслийн зорилго, хамрах хүрээ, нэр томьёо,
  ажлын задаргаа болон өмнөх шийдвэрүүдтэй зөрчилдөхгүй байна.

## Эхлээд судлах дараалал

1. Тухайн семинарт хамаарах `lectures/` доторх лекцийг уншина.
2. `seminar_ref_docx/` доторх холбогдох заавар, хүснэгт, шаардлагыг шалгана.
3. `done_seminars/Copy of wbs.docx`-оос манай төслийн өмнөх мэдээллийг авна.
4. Даалгаврын яг ямар үр дүн шаардаж байгааг товч тодорхойлно.
5. Дараа нь л шинэ хариулт, хүснэгт эсвэл DOCX ажил үүсгэнэ.

## Материалын холбоо

- `Lesson3.pdf` болон `SPM_Seminar3_WBS_IoT (2).docx` - WBS боловсруулахад.
- `Lesson4_1.pdf`, `Lesson4_2 (1).pdf` болон
  `SPM_Lab4_Tailoring_Project_Evaluation (3).docx` - Tailoring, төслийн
  үнэлгээ, cost-benefit/value analysis хийхэд.
- `Lesson5.pdf` болон `Seminar5_Effort_Estimation_MN (1).docx` - effort,
  хугацаа, хүний нөөцийн тооцоо хийхэд.

## Ажил хийх дүрэм

- Хариултыг NUM-ийн 4-р түвшний оюутны бодит түвшинд, энгийн бөгөөд
  багшид тайлбарлаж чадахаар бичнэ.
- Даалгавар англи хэл шаардаагүй бол байгалийн монгол хэл хэрэглэнэ.
- Лекцийн аргачлал, томьёо, нэр томьёог баримтална.
- Тооцоолол байвал үндсэн алхам болон ашигласан таамаглалыг харуулна.
- Мэдээлэл дутуу үед үндэслэлтэй, энгийн таамаглал хийж түүнийгээ тэмдэглэнэ.
- Хэт мэргэжлийн, байгууллагын хэмжээний тайлан шиг болгож хүндрүүлэхгүй.
- Багийн гишүүд, төслийн нэр, WBS код, ажлын нэрийг дур мэдэн өөрчлөхгүй.
- Шинээр дууссан семинарын эцсийн файлыг `done_seminars/` дотор байрлуулна.
- Эх файл болон багшийн материалыг өөрчлөхгүй; шаардлагатай бол шинэ файл үүсгэнэ.

## Дуусгахын өмнөх шалгалт

- Даалгаврын бүх асуулт, хүснэгт, хэсгийг бөглөсөн эсэх.
- Тооцооны тоо хоорондоо зөрөөгүй эсэх.
- Шинэ ажил өмнөх WBS болон Tailoring шийдвэртэй нийцэж байгаа эсэх.
- Монгол хэл, гарчиг, хүснэгтийн нэр ойлгомжтой эсэх.
- DOCX/PDF файл нээгдэж, хүснэгт болон текст тасраагүй эсэх.

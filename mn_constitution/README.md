# mn_constitution — Монгол Улсын Үндсэн хуулийн код ревью

Үндсэн хуулийг программ мэт загварчилж, алдаа (bug), сул тал, найруулгын доголдлыг автоматаар илрүүлнэ.
Эх сурвалж нь **албан ёсны монгол эх** (`constitution/text/undsen_khuuli_mn.txt`, legalinfo.mn lawId=367).

```
python3 -m pytest -q             # 12 тест
python3 -m constitution.report   # out/report.json, out/REPORT.md
python3 explorer/build.py        # out/explorer.html
python3 -m constitution.uml      # docs/UML.md, out/uml.html
python3 -m constitution.trace pm_dismissal motion_by_quarter debate_after_3_days vote_majority_total president_veto
python3 -m constitution.trace veto president_vetoes override_fails --statutes   # Үндсэн хууль + хууль (⚖)
python3 scripts/ingest_archive.py status   # хуулиудын корпус (web.archive.org-оос), constitution/text/laws/
python3 -m constitution.laws               # корпус + Үндсэн хуулийн шилжүүлсэн 61 өгүүлбэр
```

Хуулиуд: legalinfo.mn шууд хүрэх боломжгүй тул web.archive.org-ийн хамгийн сүүлийн хуулбараас авна.
Зөвхөн «МОНГОЛ УЛСЫН ХУУЛЬ» толгойтой, «Энэ хуулийг … хүчингүй болсонд тооцсон» тэмдэглэлгүй хуулийг хадгална
(`in_force=None` = хүчингүй тэмдэглэл олдоогүй, баталгаажаагүй).

## Бүтэц

| Файл | Үүрэг |
|---|---|
| `text/undsen_khuuli_mn.txt` | Монгол эх, үгчлэн |

| `procedures.py` | 8 процедур төлөвт машин (Ерөнхий сайд огцруулах, хориг, онц байдал, Цэц, …) |
| `checks.py` | Шалгах дүрмүүд; ишлэл бүрийг `q()` монгол эхээс үгчлэн шалгана |
| `stress.py` | 7 стресс тест (хуультай хамт дахин ажиллуулна) |
| `laws.py` | Хуулийн задлагч, `q_law()` үгчлэн ишлэл, бүртгэл, шилжүүлэлтийн холбоос |
| `statutes.py` | Хуулиар хэсэгчлэн хаагдсан олдвор, хуулиас үүдэлтэй шинэ олдвор |
| `statute_machines.py` | Төлөвт машины хуулийн давхарга: шинэ шилжилт, хугацаа, төлөвийн тэмдэглэл |

## Шалгах дүрэм

- `UNDEFINED_TRANSITION` — бодитоор тохиолдож болох үйл явдлын үр дагавар заагаагүй
- `STALL_POINT` — үүрэгтэй тоглогч хугацаа, анхдагч үр дагаваргүй (юу ч хийхгүйгээр гацаана)
- `THRESHOLD_INVERSION` — хориг даван туулах босго хууль батлахаас бага
- `SELF_ENTRENCHMENT` — нэг нам Үндсэн хуулийг дангаараа өөрчлөх
- `UNBOUNDED_DELEGATION` — хуульд хязгааргүй шилжүүлсэн
- `UNDEFINED_TERM`, `UNDEFINED_THRESHOLD`, `WEAK_MODALITY`, `VERSION_MISMATCH` …

## Анхааруулга

- 21.1-ийг legalinfo.mn-ийн 2026-04-21-ний web.archive.org хуулбараас шинэчилсэн (126 гишүүн, 78 + 48). Хуучин эхэд «далан зургаан» байсан нь манай файлын алдаа байв.
- Үндсэн хууль олон зүйлийг органик хуульд (УИХ-ын тухай, Цэцэд маргаан хянан шийдвэрлэх ажиллагааны тухай, …) даатгадаг. Тэдгээр хуулийг загварт оруулаагүй тул «Үндсэн хуульд заагаагүй» гэсэн олдвор хуулиар хэсэгчлэн шийдэгдсэн байж болно.
- Модаль ангилал regex-д тулгуурласан ойролцоо утга. Засварууд нь шинжилгээний санал, бодит төсөл биш.
